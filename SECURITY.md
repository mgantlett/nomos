# Security Policy

## Supported Versions

Currently, the Nomos project only provides security updates for the latest major release.

| Version | Supported          |
| ------- | ------------------ |
| 4.x.x   | :white_check_mark: |
| < 4.0   | :x:                |

## Reporting a Vulnerability

We take the security of our deterministic execution substrate very seriously. A vulnerability in the deterministic execution substrate could result in rogue autonomous behavior, IP leakage, or destruction of local state.

If you discover a vulnerability, we ask that you report it to us immediately via email at **nomos-security@sophialabs.ca**.

**Please do not report security vulnerabilities through public GitHub issues.**

In your report, please include:
- A description of the vulnerability.
- Steps to reproduce the issue.
- Potential impact on the deterministic execution boundary.

You should receive an acknowledgment within 48 hours, and we will keep you updated on our progress toward a fix. We endeavor to resolve critical issues promptly, prioritizing anything that bypasses the 42 Definition of Done (DoD) Quality Gates or violates the 7 Laws of Deterministic Engineering.
